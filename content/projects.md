# projects

- [URL Shortener](https://github.com/xavierchen0/urlshortener)
  - **Built with**: HTMX, TailwindCSS, Python, Flask
  - Try it [here](https://urlshortener-74dy.onrender.com/)! Warning: I am
    running this on a free database, and it refreshes every month 🤷‍♂️ (i.e. any
    url stored for longer than one month is deleted). Use at your own risk!
  - A simple URL shortener for my own personal use. And a fun little project for
    me to try HTMX for the first time! I immediately fell in love with HTMX
    afterwards.
- [hooks.nvim](https://github.com/xavierchen0/hooks.nvim)
  - **Built with**: Lua, NeoVim.
  - A NeoVim plugin that allows you to easily tag files with a keyboard shortcut
    and jump to it with the same keyboard shortcut. It is git-local which means
    that every keyboard shortcuts you have set is only saved for that git
    repository. Different repo, Different keyboard shortcuts! It also provides
    an editable menu for you to quickly adjust the keyboard shortcuts on the
    fly!
  - The idea for this plugin was born because during my development I am often
    only touching a few files at any point in time (e.g. config file, working
    file, abstract class file). Instead of using my search tool (i.e.
    [fzf](https://github.com/junegunn/fzf)) to find the files to go to by name,
    I can just quickly jump to it with the keyboard shortcut that I have set!
- [SMU Facility Booking System (FBS) Auto-Booker](https://github.com/xavierchen0/smu-fbs-auto-booker)
  - **Built with**: Javascript, Playwright, Cron.
  - A web automation script I built to book my favourite study rooms at SMU
    automatically. Paired with a cron job, it runs entirely on its own. No more
    staying up until midnight, competing with everyone else for a room, or
    dealing with the FBS server's questionable stability. Just go to bed and
    wake up knowing your favourite study room is already booked!
- [Flux | IOS App to Visualise Noise](https://github.com/xavierchen0/flux)
  - **Built with**: Swift
  - This was actually my submission for
    [Apple Swift Student Challenge](https://developer.apple.com/swift-student-challenge/) 2025.
    Unfortunately, I was not able to visit Tim Cook at Cupertino, but it was
    still a fun project to try. It made me learn about how incredibly sensitive
    and accurate our iPhones' microphones actually are. With some calibration
    and a little maths to convert microphone readings into sound pressure levels
    (decibels), you can get surprisingly accurate measurements of the noise
    around you, at least within certain noise limits!
- [C++ Financial Instruments Pricer](https://github.com/xavierchen0/cpp_pricer)
  - **Built with**: C++, CMake
  - This is a multi-threaded C++ Financial Instruments Pricer to help with the
    pricing of Options, Bonds and Swaps with implemented algorithms of CRR and
    JRR Binomial Tree Pricer. This was actually a class project I had done in
    SMU for my Master's programme. It was quite interesting as it was my first
    time building a project with C++.
